Shapix

Shapix is a simple and modern image editing tool that lets you crop images into different shapes directly in your browser.

✨ Features

- Upload images directly from your device
- Crop images into different shapes
- Move, zoom, and rotate images
- Transparent PNG export
- Works on mobile and desktop
- Image processing happens locally in the browser

🚀 Getting Started

Open the website and upload an image to start editing.

No installation or account is required.

🔒 Privacy

Images are processed locally in the browser and are not uploaded to a server.

🛠️ Built With

- HTML
- CSS
- JavaScript
- Canvas API

📌 Project Status

Shapix is currently in its first version and is actively being developed.

More editing tools and features will be added in future versions.
